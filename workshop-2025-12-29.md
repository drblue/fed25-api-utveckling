# Workshop 2025-12-29

## Steg

### Steg 1

I route:n för `GET /users/:userId`, hitta den enskilda användaren med det efterfrågade id:t och svara med det objektet.

### Steg 2

Om den efterfrågade användaren inte finns, svara med `404`.

### Steg 3

Lägg till felhantering, t.ex. om användaren skickar in `apa` istället för ett ID.

## Exempel på requests

### `GET /users/1`

**Status Code:** `200`

```json
{
  "id": 1,
  "username": "johan",
  "name": "Johan Nordström",
  "email": "evil@haxx0r.org"
}
```

### `GET /users/2`

**Status Code:** `404`

```json
{
  "message": "User Not Found"
}
```

### `GET /users/4`

**Status Code:** `200`

```json
{
  "id": 4,
  "username": "pelle",
  "name": "Pelle Svanslös",
  "email": "pelle@svanslos.nu"
}
```

### `GET /users/apa`

**Status Code:** `400`

```json
{
  "message": "Invalid User ID"
}
```
